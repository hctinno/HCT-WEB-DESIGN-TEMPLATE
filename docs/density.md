# 밀도 — 지라형 고밀도 규격

## 왜 14px 인가

일반 웹사이트의 본문은 16px 입니다. 관리도구는 14px 입니다.
지라·리니어·슬랙·깃허브 모두 14px 를 씁니다.

이유는 단순합니다. 관리도구 사용자는 **하루 종일 같은 화면을 봅니다.**
한 번에 더 많은 행을 보는 것이 스크롤을 줄이고, 스크롤이 줄면 맥락 전환이 줄어듭니다.

## 타입 스케일

| 클래스 | 크기/행간 | 용도 |
|---|---|---|
| `text-micro` | 11 / 14 | 타임스탬프, 사이드바 그룹 라벨 |
| `text-xs` | 12 / 16 | 뱃지, 캡션, 입력 라벨 |
| `text-sm` | 13 / 18 | 밀집 테이블 셀, 사이드바 항목 |
| `text-base` | 14 / 20 | **기본 본문**, 버튼, 입력 |
| `text-md` | 16 / 24 | 섹션 제목 |
| `text-lg` | 20 / 28 | 페이지 제목 |
| `text-xl` | 24 / 32 | 화면 제목 |
| `text-metric` | 28 / 34 | KPI 수치 |

한 화면에서 4단계를 넘게 쓰지 마세요. 위계가 많아지면 위계가 사라집니다.

## 간격 — 4px 배수만

허용: `0 0.5 1 1.5 2 2.5 3 4 5 6 8 10 12 16 20 24`

`tailwind.config.js` 에서 spacing 을 이 값들로 제한했습니다.
**스케일 밖 값(`h-7`, `pl-7`, `p-[13px]`)은 CSS 가 생성되지 않아 조용히 무시됩니다.**
화면이 깨진 채로 넘어가기 쉬우니 `npm run lint:design` 으로 반드시 확인하세요.

실무 기준:
- 관련 요소 사이: `gap-2` (8px)
- 카드 내부 여백: `p-4` (16px)
- 카드 사이: `gap-3` (12px)
- 섹션 사이: `mb-5` (20px) ~ `mb-6` (24px)

24px 를 넘는 간격은 섹션 분리에만 씁니다.

## 컨트롤 높이

| 토큰 | 높이 | 용도 |
|---|---|---|
| `h-control-xs` | 24px | 테이블 셀 내부 버튼 |
| `h-control-sm` | 28px | 툴바, 필터 |
| `h-control-md` | 32px | **기본 버튼·입력** |
| `h-control-lg` | 36px | 주요 폼, 사이드바 항목 |

## 행 높이

| 밀도 | 높이 | 언제 |
|---|---|---|
| `compact` | 32px | 스캔이 목적인 로그·이벤트 |
| `default` | 40px | 대부분의 목록 |
| `relaxed` | 48px | 아바타·다중 행 콘텐츠 포함 |

`DensityToggle` 로 사용자가 직접 고를 수 있게 하세요. 지라·리니어가 하는 방식입니다.

## 모서리

최대 `rounded-xl` (12px). 고밀도 화면에서 큰 둥글기는 공간을 낭비하고
구획을 흐리게 만듭니다. `rounded-2xl` 이상은 이 시스템에 존재하지 않습니다.

- 뱃지·태그: `rounded-sm` (3px)
- 버튼·입력: `rounded-md` (6px)
- 카드·패널: `rounded-lg` (8px)
